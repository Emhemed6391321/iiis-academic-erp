# المعايير الطباعية الرسمية والهوية البصرية الحكومية
**دليل التنسيق الورقي، الخطوط، الهوامش، وقواعد CSS المعتمدة للطباعة**

---

## 1. الهوية البصرية وشعار المعهد المركزي

### أ. ملف الشعار ومساره المعتمد
- المسار الأساسي للشعار هو:
  - `/images/logo.png` (أيقونة وصورة دائرية فائقة الجودة)
  - `/images/logo.svg` (متجهي Vector بدقة لا نهائية للطباعة بأي مقاس)
- في حال قيام الإدارة برفع شعار مخصص جديد عبر صفحة الإعدادات الإدارية، يتم حفظه وتخزينه في مسار:
  - `/storage/branding/logo_...`
- يتم التعامل مع الرابط وفق ترتيب الأولوية البرمجي:
  ```javascript
  const activeLogo = this.adminSettings.logoPreviewUrl 
      || (this.adminSettings.profile && this.adminSettings.profile.logo_url) 
      || '/images/logo.png';
  ```

### ب. الأبعاد الطباعية المعتمدة للشعار:
- **في ترويسة السجلات العريضة (A4 Landscape)**: ارتفاع الشعار `60px` إلى `68px`، متمركز أفقياً.
- **في ترويسة الشهادات والإفادات الرسمية (A4 Portrait)**: قطر الشعار `72px` إلى `80px` في دائرة توثيقية أنيقة.
- **في بطاقة الطالب (Student ID)**: ارتفاع الشعار `28px` إلى `34px`.

## 2. الخطوط العربية الرسمية المعتمدة
للخروج بمظهر حكومي أكاديمي رصين وفخم، يتم اعتماد الخطوط التالية:
1. **الخط الأساسي للعناوين والمتون**: `Cairo` و `IBM Plex Sans Arabic` بأوزان (Bold 700، ExtraBold 800، Black 900).
2. **الخط الفرعي للبيانات الأرشيفية والأرقام**: أرقام عربية ومونو مسافة متساوية واضحة لمنع أي لبس في أرقام القيود والأرقام الوطنية.

## 3. قواعد CSS الخاصة بالطباعة (Print Stylesheet Rules)

```css
@media print {
    /* ضبط حجم وهوامش الصفحة */
    @page {
        size: A4 portrait; /* أو landscape حسب نوع الوثيقة */
        margin: 12mm 15mm 15mm 15mm;
    }

    /* إخفاء كل ما لا ينتمي للمستند الورقي */
    .no-print, nav, aside, header, button, .modal-backdrop {
        display: none !important;
    }

    /* تمكين الطباعة الدقيقة للألوان والحدود */
    body, * {
        -webkit-print-color-adjust: exact !important;
        print-color-adjust: exact !important;
        color-adjust: exact !important;
    }

    /* حماية الجداول والصفوف من الانقسام المشوه */
    tr, td, th {
        page-break-inside: avoid !important;
        break-inside: avoid !important;
    }

    /* تثبيت ترويسة الجدول في كل صفحة عند تعدد الصفحات */
    thead {
        display: table-header-group !important;
    }
    
    tfoot {
        display: table-footer-group !important;
    }
}
```

## 4. تصميم الترويسة الموحدة (Standard Header Component)

تتكون الترويسة من شبكة Flex/Grid متوازنة من ثلاثة أجزاء:
1. **اليمين (معلومات السيادة والتبعية)**:
   - اسم الدولة بخط عريض (12pt).
   - اسم الوزارة/الهيئة المشرفة (11pt).
   - اسم الإدارة المختصة (11pt).
   - اسم المعهد المركزي باللون الأزرق المعتمد (13pt Black).
   - مسمى الفرع (10pt).
2. **الوسط (شعار المعهد المركزي)**:
   - صورة الشعار المعتمد بدقة عالية مع نص "إدارة شؤون الطلاب والامتحانات" تحته.
3. **اليسار (البيانات الإدارية والتاريخ)**:
   - تاريخ الاستخراج (الموافق هجري وميلادي).
   - الرقم الإشاري للمستند.
   - العام الأكاديمي.
   - كود الأرشفة الموحد.
